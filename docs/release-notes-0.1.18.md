# Markdown Pipeline 0.1.18

**Markdown Pipeline 0.1.18.** Linux only for now: Windows and macOS are not supported in this release. Update with `mdpipeline update`. Nothing else to do.

## Changes

- Fixed: in the app's first-time setup, what you typed could be lost when the screen refreshed. If that happened to the output folder you typed, your files went to the default folder instead. If it happened to the email in the feedback form, your feedback was sent without your email. The setup screens now keep what you type.

## If you set up a pipeline with 0.1.17

- On the app's home screen, each pipeline shows the folder its files go to. If it is not the folder you chose, your files are in the default folder: `~/markdown-pipeline/` followed by the pipeline name.
- If you sent feedback and want a reply, please send it again with your email.

## Usage data (only if you chose "Share usage")

- No change.
