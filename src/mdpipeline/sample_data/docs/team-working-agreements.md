# Team working agreements

- Sprints are two weeks. Planning is on the first Monday, the demo on the last Thursday.
- A bug that affects invoice totals is always the top priority.
- Every pull request needs one review. Changes to billing code need two.
- A decision made in a comment is repeated in the epic's description, so it can be found later.
- We close duplicates the same day we notice them.
